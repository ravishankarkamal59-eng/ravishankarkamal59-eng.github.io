🔑 Token कैसे बनाएँ?

  1. github.com/settings/tokens/new खोलें
  2. Note: admin-panel
  3. Expiration: No expiration
  4. Scopes: ✅ repo वाला box tick करें

  6. Token copy करके ऊपर paste करें
